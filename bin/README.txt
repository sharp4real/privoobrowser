Optional: place the yt-dlp binary here for media downloads from the new tab page.

Windows: save as yt-dlp.exe in this folder.
macOS / Linux: save as yt-dlp and chmod +x.

Download: https://github.com/yt-dlp/yt-dlp/releases

Alternatively, install yt-dlp on your PATH or set a custom path in Settings → Media.
