Privacy and security

What the Privacy Shield does
The shield icon in the toolbar isn't one setting, it's a status display for the toggles below: ad & tracker blocking, Force HTTPS, third-party cookie blocking, Encrypted DNS, anti-fingerprinting, and WebRTC IP protection. Each one runs (or stops) independently and takes effect immediately when you flip it here, no restart needed, unless a toggle's own description says otherwise. Turning a protection off here means it's genuinely off, not just hidden from the shield panel.
Ad and tracker blocking
Block common ads and trackers. Takes effect immediately, in both directions.
Cryptojacking protection
Blocks known in-browser cryptomining scripts that hijack your CPU without asking. Applies after you restart Privoo.
Filter lists
Choose which built-in lists to use, or add your own. Changes apply after you restart Privoo.
Your lists
Force HTTPS
Upgrade insecure pages when possible.
Show HTTPS upgrade notice
Display a 3-second splash when Privoo upgrades a site to HTTPS.
Third-party cookies
Cookies set by a site other than the one you are visiting. Blocking them is the main defence against being followed between sites; allowing them can fix sign-ins and embedded content that break without them.
Encrypted DNS (DNS-over-HTTPS)
Encrypts your DNS lookups end-to-end. Strict mode, never falls back to your ISP's plaintext DNS, so no leaks.
DNS provider
Cloudflare, 1.1.1.1, the default.
Custom DNS-over-HTTPS URL
Full https:// URL of your DoH endpoint, typically ends in /dns-query.
Block adult content (18+)
Routes DNS through a family-safe resolver (Cloudflare / AdGuard family filters) that blocks pornography and known malware domains. Requires Encrypted DNS to be on.
Paste protection
Check a link before you follow it when you paste one into the address bar. Warns about the handful of tricks used to make an address read as one site while pointing at another — a name hidden before an @, characters that only look like letters, a well-known brand on somebody else's domain.
Block pop-ups
Only let a page open a new tab or window if you just interacted with it. Links, sign-in popups and downloads all follow a click, so they still work; pop-unders and timed ad redirects do not.
Do Not Track
Send the DNT request header.
Spoof user agent
Hides your real browser and OS signature from sites.
Canvas fingerprint protection
Adds subtle noise to canvas reads to prevent tracking.
WebRTC IP protection
Prevents WebRTC from leaking your real IP address.
Stronger tracking protection
Stops sites recognising you across the web by the link you arrived on. Removes the tracking tags appended to URLs (utm_*, fbclid, gclid), tells a site you came from a domain rather than an exact page, and sends the Global Privacy Control signal. On by default — it costs nothing and breaks nothing.

Privoo Guard

On-demand malware scanning
Privoo Guard scans files with ClamAV, an open-source antivirus engine. It is a separate optional component: Privoo does not bundle it, because the engine and its signature database are large and GPL-licensed. Install it once and Privoo will drive it from here.
Checking…
Enable Privoo Guard
Show scanning controls and let Privoo run ClamAV. Off by default.
Install ClamAV
Privoo will download the portable ClamAV engine and its virus signatures in the background. Nothing is installed system-wide and no administrator rights are needed. It all lives in your Privoo profile folder. The signature database is a few hundred megabytes, so the first run takes a while.

Accessibility

Seeing the browser

Interface size
Scales the tab strip, toolbar and panels. It leaves web pages alone, because those have their own zoom on Ctrl + and Ctrl −.
Higher contrast
Takes the greys out of the interface. Secondary text becomes full strength, and every hairline gets darker. Transparency is switched off while this is on, since a wash over text works against reading it.
Heavier text
Thickens the interface text without enlarging it. A heavier stroke is often easier to read than a bigger one, so this is separate from Interface size and the two can be used apart.
Always show the focus outline
Normally the outline only appears when you move with the keyboard. With this on it appears whenever anything is focused, so it is always clear where you are.
Stop interface animation
Nothing in the browser fades, slides or scales. Separate from the system setting, so you can have a still browser without a still computer.

Seeing web pages

Minimum text size
A floor, not a zoom. Text already larger than this is left as it is, so a page keeps its own headings and hierarchy and only the small print grows.
Underline every link
Many sites mark links with colour alone, which does not help if colours are hard to tell apart. This underlines them everywhere.

Read aloud

Read text under the pointer
Rest on a paragraph, a heading, a link or a button and Privoo speaks it. It works on web pages and on Privoo itself, so a tab title and a toolbar button are read the same way a paragraph is.
Move through the page with the keyboard
Hold Alt and press the down or up arrow to step through a page one block at a time, each one read out and scrolled into view. Alt and Space repeats the current one, and Escape stops. No pointer needed.
Speaking speed
Uses whichever voice Windows is already set to, so it matches the rest of the system rather than introducing a different one.
Worth being straight about who this helps. Reading on hover means aiming a pointer at text you can already see well enough to aim at, so it is at its best for low vision, or for anyone who finds long stretches of reading hard. If you cannot see the screen at all, the keyboard stepping above is the part built for you, and a real screen reader is still better than this: Narrator, NVDA and VoiceOver announce controls, states, tables and page landmarks, and they do it in every application rather than only in the browser. Privoo works alongside all of them, and this can be left off if you use one.

Night light

Warm the screen
Takes the blue out of the whole window, the toolbar and tab strip included, not just the page. Blue light late in the evening is the part that keeps you awake, and a warm screen is easier to read against a dark room.
Only in the evening
Switches itself on and off at the hours below. Privoo uses the clock rather than the real sunset, because working out sunset means knowing where you are, and Privoo does not ask.

Distance breaks

Remind me to look away
A small card in the corner every so often, asking you to focus on something far off for twenty seconds. It never covers the page and it never takes the keyboard, and it goes away on its own if you ignore it.
To be straight about what this is: no browser setting can prevent shortsightedness, and one claiming to would be lying to you. What research does support is not holding a single close focus for hours at a time, which is the twenty twenty twenty rule, and time spent outside in daylight, which matters more than anything on this page and is not something software can give you. Privoo can do the one part it is placed to do, which is notice that you have been reading for an hour and say so.
Screen readers and magnifiers
Privoo deliberately does not include its own. Windows Narrator and Magnifier, VoiceOver on macOS, and Orca on Linux are better than anything that could be built into one application, and Privoo works with all of them. A worse copy of a system feature would not be a kindness.
