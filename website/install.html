Privoo Desktop: Installation

From the Privoo reference. This article covers version 6.0.0.

Main article: Privoo Desktop

Privoo Desktop is distributed only through GitHub Releases. There is no app store listing on any platform, and the installers are not code-signed, so each operating system shows an unfamiliar-publisher warning the first time you run one. This is expected, and is a direct consequence of the project not holding a paid code-signing certificate rather than any problem with the build itself.

Unsigned builds

Privoo Desktop is not notarised on macOS and not code-signed on Windows. Both operating systems will warn that the publisher is unrecognised. The steps below cover how to proceed past that warning on each platform.

Windows

  1. Download Privoo-Setup-<version>.exe from the latest release.
  2. Run the installer. Windows SmartScreen will show "Windows protected your PC" because the executable is unsigned. Click More info, then Run anyway.
  3. The installer is not a silent one-click install: it lets you choose the installation directory, and creates a desktop shortcut and a Start Menu entry.

macOS

  1. Download the .dmg for your Mac's chip from the latest release: the arm64 build for Apple Silicon (M1 and later), or the x64 build for an Intel Mac.
  2. Open the disk image and drag Privoo into Applications.
  3. On first launch, Gatekeeper will refuse to open the app because it is not notarised by Apple. Right-click (or Control-click) the app in Applications and choose Open, then confirm Open in the dialog. This only needs to be done once; opening it normally afterward works as expected.

Linux

Three package formats are published for x86-64. Use whichever your distribution supports.

Linux packages
FormatTypical useRun
AppImageAny distribution, no installation requiredchmod +x Privoo-*.AppImage && ./Privoo-*.AppImage
.debDebian, Ubuntu and derivativessudo dpkg -i privoo_*.deb
.rpmFedora, openSUSE and derivativessudo rpm -i privoo-*.rpm

Distribution-specific dependency resolution is not handled by these packages; if dpkg or rpm reports missing dependencies, install them with your package manager's dependency-fix command (for example sudo apt --fix-broken install on Debian-based systems) and retry.

Updating

Automatic updates are enabled by default and check the GitHub release feed periodically. When a newer version is available it downloads in the background and applies on the next restart. This can be turned off in Settings. AppImage, .deb and .rpm Linux packages are not self-updating; a new version must be downloaded and reinstalled manually.

Uninstalling

Uninstalling by platform
PlatformMethod
WindowsSettings → Apps, or run the uninstaller in the install directory
macOSDrag Privoo.app from Applications to the Trash
Linux (.deb)sudo apt remove privoo-browser
Linux (.rpm)sudo rpm -e privoo-browser
Linux (AppImage)Delete the .AppImage file

Uninstalling the application does not remove your profile data (history, bookmarks, settings, saved passwords). See Data storage in the main article for the configuration directory on each platform, and delete it manually if a clean removal is needed.
