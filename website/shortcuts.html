Privoo Desktop: Keyboard shortcuts

From the Privoo reference. This article covers version 5.0.6.

Main article: Privoo Desktop. See also Browsing.

On macOS, substitute Cmd for Ctrl throughout. Shortcuts are forwarded from page content to the browser interface, so they function while focus is inside a page rather than only on the browser's own controls.

Internal pages

Privoo's own pages are served from the privoo:// scheme, registered as a privileged, standard and secure scheme so that the pages receive an ordinary origin and behave as normal web documents.

Internal page addresses
AddressPage
privoo://newtabSpeed Dial, the new tab page
privoo://settingsSettings
privoo://extensionsBuilt-in and installed tools
privoo://marianaAnonymous hosting management
privoo://identitiesSaved identities for autofill
privoo://historyHistory
privoo://bookmarksBookmarks
privoo://downloadsDownloads
privoo://aiPrivoo AI
privoo://newsRelease notes, rendered locally
privoo://incognitoIncognito landing page
