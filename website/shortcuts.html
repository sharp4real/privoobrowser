Keyboard shortcuts

On macOS, use ⌘ wherever Ctrl is listed. If you only learn one of these, learn Ctrl K. The command palette can reach almost everything else on this page.

Tabs

Ctrl TNew tab
Ctrl WClose tab
Ctrl Shift TReopen the tab you just closed
Ctrl TabNext tab
Ctrl 1 … 8Jump to that tab
Ctrl 9Jump to the last tab
Ctrl Shift ASearch open tabs

Navigation

Ctrl LFocus the address bar
Ctrl R · F5Reload
Alt ←Back
Alt →Forward

Features

Ctrl KCommand palette, everything from one field
Ctrl HHistory
Ctrl JDownloads
Ctrl NNew window
Ctrl Shift NNew incognito window
Ctrl Shift ESplit view
Ctrl Shift RReader mode
Ctrl Shift FFocus mode
F12Developer tools

Zoom

Ctrl +Zoom in
Ctrl −Zoom out
Ctrl 0Reset zoom
