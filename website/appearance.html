Privoo Desktop: Appearance

From the Privoo reference. This article covers version 5.0.6.

Main article: Privoo Desktop

Privoo ships as a dark browser with a lavender accent. Almost every element of that presentation is configurable, and the interface is deliberately built so that a single accent value propagates through it.

Accent colour

A single accent colour, configured in Settings → Appearance, propagates through the entire interface: tabs, toggles, buttons, panels, the new tab page and the shield. The interface derives its surfaces from the accent rather than applying it as a highlight on isolated controls, which is why changing it alters the character of the whole browser rather than one detail.

The default is lavender, #8b7cf7. The accent is also applied to page favicons in certain interface contexts.

Note on documentation drift

The project README lists an older accent default of #57a97e (green), which predates the 5.x visual redesign. The value defined in the settings store, and used by the shipping browser, is #8b7cf7.

Light and dark

Dark is the default; light is a setting. A separate Force dark mode option inverts pages that provide no dark theme of their own. Sites that do provide one are left to use it, and Privoo's own internal pages follow the user's explicit choice rather than being inverted.

Transparency and glass

Increase transparency renders the browser's surfaces as frosted glass so that the desktop is visible through them. It uses the operating system's own material rather than simulating one with a flat tint:

Materials by platform
PlatformMaterial
WindowsMica or Acrylic, via the window background material API.
macOSVibrancy.
Other or unsupportedFalls back to CSS translucency.

On operating systems lacking the relevant API, Privoo degrades to plain translucency rather than failing.

Your Vibe

An ambient hue applied across the interface, tinting the browser chrome and the new tab page in concert. It is a subtler adjustment than the accent and affects the overall cast of the window rather than any individual control.

The clock, weather, greeting, shortcut tiles and privacy statistics are each individually switchable, so the page may be configured to show a search field and nothing else.

Custom CSS

This styles the real interface rather than exposing a constrained theming API. A rule that breaks the layout will break the layout; clearing the field restores the default presentation.

Search engines

Brave Search is the default, selected because it does not build a profile of the user. The following are built in, and any other engine may be added by URL using a %s placeholder for the query.

Google, Bing, DuckDuckGo, Brave, Startpage, Ecosia, Qwant, Yandex, Kagi, or custom.

The selected engine's icon is displayed in the Speed Dial search field.

Discord Rich Presence

Optional and disabled by default. When enabled it can indicate that Privoo is in use, and optionally synchronise the accent colour to the presence card. It does not publish visited sites.
